# Security Policy

Quorum handles real voter PII (names and emails from Google/Microsoft
sign-in) and vote data, so security reports are taken seriously.

## Supported versions

This project doesn't currently cut versioned releases — security fixes are
applied to the `main` branch.

## Reporting a vulnerability

**Please do not open a public GitHub issue for a security vulnerability.**

Use GitHub's private vulnerability reporting instead: go to the
[Security tab](../../security/advisories/new) of this repository and click
"Report a vulnerability." This opens a private advisory visible only to the
maintainers, so the issue isn't disclosed publicly before a fix is ready.

(If that option doesn't appear, it means the maintainer hasn't enabled
private vulnerability reporting for this repo yet — in that case, please
flag it through any other channel you have for reaching the maintainer
rather than filing a public issue.)

Please include:

- A description of the vulnerability and its potential impact.
- Steps to reproduce it.
- Any relevant logs, screenshots, or proof-of-concept code.

We'll acknowledge reports as soon as possible and work on a fix before any
public disclosure.
